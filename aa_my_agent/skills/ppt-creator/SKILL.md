# PPT 演示文稿规划与设计

这个技能帮助用户系统性地规划 PowerPoint 演示文稿的结构、内容和视觉设计，
确保最终产出的 PPT 逻辑清晰、视觉美观、信息传达高效。

---

## 工作流程

### 第一步：需求调研

在开始规划之前，先和用户确认以下关键信息（如果用户没提供，主动提问）：

| 维度 | 关键问题 |
|------|----------|
| **目标** | 这个PPT的目的是什么？（汇报/说服/教学/宣传） |
| **受众** | 听众是谁？（领导/客户/学生/大众）人数多少？ |
| **时长** | 演讲时长？大概多少页合适？ |
| **场景** | 投屏演讲 / 打印阅读 / 在线发送？ |
| **风格** | 正式商务 / 创意活泼 / 简约学术？ |
| **品牌** | 是否有公司模板、Logo、色系要求？ |

**原则**：不要一次性抛出所有问题。先从最重要的 2-3 个问题开始（目标、受众、时长），
根据回答再追问细节。这会让对话更自然。

### 第二步：确定整体结构

根据 PPT 类型套用合适的结构框架：

#### 1. 汇报型（季度汇报、述职、项目汇报）
```
封面 → 目录 → 核心指标总览 → 分项详述（3-5页）→ 问题与挑战 → 下阶段计划 → 结语
```

#### 2. 演讲型（行业大会、TED风格、对外分享）
```
封面（引人注目）→ 痛点/问题 → 核心观点 → 论据1-3 → 案例 → 总结升华 → Q&A
```

#### 3. 产品发布型
```
悬念开场 → 用户痛点 → 产品亮相 → 核心功能（3个）→ 场景演示 → 价格/渠道 → CTA
```

#### 4. 教学课件型
```
目标说明 → 知识铺垫 → 核心内容（分节）→ 案例练习 → 要点回顾 → 课后任务
```

**原则**：以上是"默认模板"，根据实际情况灵活调整。核心是保证逻辑线清晰——
用户听完能回答三个问题：**讲了什么？为什么重要？我该做什么？**

### 第三步：逐页内容规划

对每一页幻灯片，明确以下要素：

```
第X页 | 类型：[封面/目录/内容/过渡/总结]
标题：[一句话概括本页核心信息]
核心信息：[听众离开这一页时应该记住的一件事]
内容要点：
  - 要点1
  - 要点2
  - 要点3
视觉建议：[图表/图片/图标/排版建议]
备注：[演讲时额外要说的话]
```

**关键原则**：
- **一页一个核心信息**——不要让听众猜你想说什么
- **标题即结论**——用"销售额增长30%"替代"Q4销售情况分析"
- **少即是多**——每页正文不超过 3-4 个要点，每个要点不超过两行

### 第四步：设计建议

#### 配色原则
- **主色**占 60%（背景、大面积色块）
- **辅助色**占 30%（标题栏、图表主色）
- **强调色**占 10%（关键数据、行动按钮）
- 一个PPT不超过 3-4 种颜色
- 推荐配色工具思路：用品牌 Logo 取色，或用互补色/邻近色搭配

#### 中文字体建议
| 用途 | 推荐字体 | 备选 |
|------|---------|------|
| 标题 | 思源黑体 Bold / 微软雅黑 Bold | 造字工房力黑 |
| 正文 | 思源黑体 Regular / 微软雅黑 | 宋体（学术场景） |
| 数据 | Arial / DIN（数字更清晰） | Roboto |
| 注释 | 思源黑体 Light（小字仍清晰） | — |

**原则**：一个PPT中文字体不超过 2 种，英文/数字字体不超过 1 种。避免使用
楷体、隶书等装饰性强的字体（除非有特定文化场景需求）。

#### 排版要点
- **对齐**：所有元素必须有明确的对齐线，不要"凭感觉放"
- **留白**：内容区域不超过页面的 70%，留出呼吸感
- **层次**：通过字号（标题≥28pt，正文≥18pt）、颜色深浅、粗细来区分层级
- **统一**：同类元素（页码、标题位置、图标风格）在所有页面保持一致

### 第五步：图表与数据可视化

#### 选图原则
根据数据关系选择正确的图表类型：

| 数据关系 | 推荐图表 | 中文场景注意 |
|----------|---------|-------------|
| 比较大小 | 柱状图/条形图 | 类别标签长时用条形图 |
| 趋势变化 | 折线图 | 不超过 4 条线 |
| 占比构成 | 饼图/环形图 | 切片不超过 6 个，从12点方向开始 |
| 分布关系 | 散点图/气泡图 | 专业场景使用 |
| 流程步骤 | 流程图/箭头图 | 中文标注需精简 |

#### 图表设计要点
- **去繁就简**：去掉默认的网格线、图例边框、背景色
- **突出核心**：用强调色标注最关键的数据点或柱子
- **直接标注**：把数据标签直接放在图形旁边，而非依赖图例
- **标题即结论**：图表标题写成"华东区Q4增速领跑，达+25%"而不是"各区域增速对比"

### 第六步：输出交付物

完成规划后，输出以下内容：

```
# [PPT主题名称]

## 一、基本信息
- 目的：
- 受众：
- 时长/页数：
- 风格：

## 二、整体结构
[用流程图或编号列表展示整体章节]

## 三、逐页规划
[每页包含：页号、类型、标题、核心信息、内容要点、视觉建议]

## 四、设计建议
- 配色方案：
- 字体方案：
- 图表建议：

## 五、演讲备注
[关键过渡句、互动环节、时间分配建议]
```

## 中文 PPT 特别注意

1. **标题长度**：中文每个字宽度相同，标题控制在 15 个字以内，否则换行难看
2. **行间距**：中文正文建议 1.3-1.5 倍行距，否则显得拥挤
3. **标点统一**：全篇统一使用中文标点（，。）或英文标点（, .），不要混用
4. **数字格式**：中文环境数字超过 5 位用"万/亿"单位，如"1,200万"而非"12,000,000"
5. **成语/口号**：适当使用四字短语增强节奏感，但不要过度堆砌
6. **英文混排**：中英文之间加空格，如"我们使用 AI 技术"

## 示例对话

**用户**："帮我做一个关于新能源汽车市场分析的PPT，要给投资人看的，20分钟"

**你应该这样回应**（展示思路，不必逐字照搬）：

> 好的！给投资人做新能源汽车市场分析的PPT，20分钟大概控制在12-15页比较合适。
> 在开始规划之前，我想确认几个关键点：
> 1. 你是想说服投资人投资你的项目，还是给他们做行业趋势分享？
> 2. 投资人对新能源汽车的了解程度如何？
>
> 这样我可以帮你把结构和侧重点调整到最合适的方向。

然后在获得信息后，按照工作流程逐步输出结构规划、逐页内容、设计建议。

## 质量自检清单

完成规划后，自查以下问题：

- [ ] 能否用一句话概括整个PPT的核心信息？
- [ ] 每一页是否只有一个核心信息？
- [ ] 结构是否符合"开头吸引→中间充实→结尾有力"的逻辑？
- [ ] 是否给出了具体的视觉建议（而非泛泛的"放一张图"）？
- [ ] 图表类型是否和数据关系匹配？
- [ ] 字体、配色、排版是否有明确建议？
- [ ] 是否考虑了中文排版的特殊性？
